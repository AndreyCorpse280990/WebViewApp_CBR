# WebViewApp_CBR

Простое Android приложение для открытия сайта [ЦБ РФ](https://cbr.ru) с использованием WebView.

## Функции приложения
- Загружает сайт https://cbr.ru сразу после запуска.
- Кнопка "Назад" возвращает по истории WebView.
- Кнопка "Закрыть приложение" с подтверждением.
